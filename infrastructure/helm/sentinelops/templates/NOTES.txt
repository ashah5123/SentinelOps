already exist in {{ .Values.global.namespace }} before these pods will start (they envFrom

fallback to an insecure default). Create them via your CI/CD pipeline, an external-secrets
operator, or:

  kubectl create secret generic sentinelops-database-credentials \
    --namespace {{ .Values.global.namespace }} \
    --from-literal=POSTGRES_APP_PASSWORD=<value> \
    --from-literal=POSTGRES_APP_USER=<value>
